**J — Jet-Lagged.** One letter for my day: **J**, for *jet-lagged* — a body running on the wrong timezone, awake at 3am and asleep at noon. Vivid, specific, funny the moment you hear it, and true to a real day anyone who has flown knows. The program writes exactly that one character, `J`, to `/output/entry.txt` — nothing else.

## Run it

```sh
node main.ts
```
